
# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a Bash-based project that calculates simple interest using the principal amount, rate of interest, and time period entered by the user.

## Objective
The objective of this project is to develop a simple command-line application that helps users calculate simple interest quickly and accurately.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Input Parameters
- Principal Amount
- Rate of Interest (in percentage)
- Time Period (in years)

## Features
- Easy-to-use calculator.
- Accepts user input.
- Calculates simple interest automatically.
- Displays the calculated interest.

## Technology Used
- Bash Scripting
- Git
- GitHub

## Example Calculation
Principal Amount: 10000
Rate of Interest: 5%
Time Period: 2 years

Simple Interest: 1000

## How to Run
1. Open the terminal.
2. Run the following commands:

chmod +x simple-interest.sh
./simple-interest.sh
